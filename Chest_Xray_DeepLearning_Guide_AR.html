قاموس التقنيات الأساسية

التقنيةالمعنىلماذا هنا؟
Transfer Learningاستخدام شبكة تعلمت سابقاً ثم تكييفها.البيانات الطبية المحدودة لا تكفي غالباً لتدريب CNN ضخمة من الصفر.
Backbone / Headالجسم يستخرج features، والرأس يحولها إلى درجات الفئات.يسمح بتجميد الجسم أو fine-tuning مع رأس جديد.
Group splitتقسيم بحسب المريض/المجموعة لا بحسب الصورة.يمنع تسرب صور الشخص نفسه بين التدريب والاختبار.
Cross-Validationتكرار التدريب والتحقق عبر عدة folds.قياس أكثر استقراراً من تقسيم واحد، مع تكلفة تدريب أعلى.
OOFتنبؤ لكل عينة من fold لم يتدرب عليها النموذج.مناسب لاختيار TTA والمعايرة دون استعمال Test.
EMAمتوسط متحرك للأوزان عبر خطوات التدريب.قد يعطي أوزاناً أكثر استقراراً للتقييم.
AMPحساب مختلط الدقة.تسريع وتقليل VRAM على GPU المتوافق.
MixUp / CutMixمزج صور/مناطق وأهدافها.Regularization يقلل حفظ أمثلة التدريب.
TTAتنبؤات عدة تحويلات للصورة ثم دمجها.قد يحسن الثبات، لكنه يرفع زمن inference.
Temperature scalingتعديل حدة توزيع الاحتمالات بقسمة logits على T.معايرة confidence دون تغيير argmax عند T موجب.
Grad-CAMخريطة تقريبية لمناطق أثرت في score فئة.فحص shortcut learning بصرياً، وليس تفسيراً طبياً.

الإعدادات والبذرة العشوائية

CFG تجمع معاملات التجربة في مكان واحد بدلاً من توزيعها في الكود. هذا يسهل تغيير حجم الصور، عدد epochs، معدل التعلم، عدد الطيات، وغيرها. seed تقلل اختلاف النتائج الناتج عن العشوائية، لكنها لا تضمن تطابقاً حتمياً على كل GPU/نظام. cudnn.benchmark قد يسرّع التنفيذ مع أشكال إدخال ثابتة لكنه ليس الخيار الأكثر حتمية.

@dataclass
class CFG:
    backbone: str = "efficientnetv2_s"   # efficientnetv2_s | convnext_tiny | densenet121 | xrv_densenet121
    img_size: int = 288
    cache_size: int = 320
    batch_size: int = 32
    epochs: int = 18
    freeze_epochs: int = 1               # تدريب الرأس فقط في أول حلقة
    warmup_frac: float = 0.1
    lr_backbone: float = 2e-4
    lr_head: float = 1e-3
    weight_decay: float = 0.05
    dropout: float = 0.3
    label_smoothing: float = 0.1
    class_weight_power: float = 0.5      # 0 = بلا أوزان، 1 = موازنة كاملة
    mix_prob: float = 0.2
    mixup_alpha: float = 0.2
    cutmix_alpha: float = 1.0
    ema_decay: float = 0.995
    monitor: str = "f1_macro"            # f1_macro | bal_acc | acc | auc
    patience: int = 6
    n_folds: int = 5
    run_folds: int = 5                   # 1 = تجربة سريعة
    test_folds: int = 6
    use_clahe: bool = True
    num_workers: int = 2                 # على Windows استخدم 0
    use_amp: bool = True
    seed: int = 42
    out_dir: str = "outputs_v4"

cfg = CFG()
cfg.use_amp = cfg.use_amp and device.type == "cuda"
Path(cfg.out_dir).mkdir(parents=True, exist_ok=True)

def seed_everything(s):
    random.seed(s); np.random.seed(s); torch.manual_seed(s); torch.cuda.manual_seed_all(s)
    torch.backends.cudnn.benchmark = True
seed_everything(cfg.seed)
print(asdict(cfg))

المعالجة المسبقة والتجميع بالتشابه

CLAHE يرفع التباين محلياً دون رفعه بشكل موحد في الصورة كلها، وقد يساعد في إبراز التفاصيل لكنه قد يضخم الضوضاء أو يغيّر المظهر الطبي. CACHE يحمل الصور بعد المعالجة في RAM لتجنب قراءة/معالجة القرص في كل epoch؛ استهلاك الذاكرة يقارب عدد الصور × أبعاد الصورة × بايت لكل pixel. dHash يختزل فروق الجوار إلى بصمة 256 بت؛ مسافة Hamming تقيس اختلاف البتات. Union-Find يربط الصور المتشابهة في مكونات، ثم يدمج المكونات مع مجموعات المرضى. حد 10 تجريبي ويجب التحقق من أنه لا يجمع صوراً مختلفة خطأً.

# ---- near-duplicate grouping (dHash 16x16 = 256 bit) ----
def dhash(a, n=16):
    s = cv2.resize(a, (n + 1, n), interpolation=cv2.INTER_AREA).astype(np.int16)
    return (s[:, 1:] > s[:, :-1]).flatten().astype(np.float32)
H = np.stack([dhash(a) for a in arrs])                  # (N, 256)
parent = list(range(len(H)))
def find(i):
    while parent[i] != i:
        parent[i] = parent[parent[i]]; i = parent[i]
    return i
def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb: parent[rb] = ra

NEAR_DUP_MAX_HAMMING = 10                                # ~4% من البتات
Hn = 1.0 - H
for s in range(0, len(H), 512):
    ham = H.shape[1] - (H[s:s+512] @ H.T + Hn[s:s+512] @ Hn.T)
    ii, jj = np.where(ham <= NEAR_DUP_MAX_HAMMING)
    for i, j in zip(ii + s, jj):
        if i < j: union(int(i), int(j))

الشبكة والخسارة وMixUp/CutMix

XrayNet يفصل backbone لاستخراج الميزات عن head للتصنيف. timm يوفر نماذج مدربة مسبقاً (Transfer Learning)، وتُزال طبقة التصنيف الأصلية عبر num_classes=0. الصور الرمادية تتحول إلى 3 قنوات لتناسب ImageNet backbones ثم تطبّع بمتوسط وانحراف معياري النموذج. نسخة torchxrayvision لها نطاق إدخال مختلف (تقريباً -1024 إلى 1024) لذا يحول [0,1] إلى ذلك النطاق. CrossEntropyLoss مع أوزان فئات مخففة وLabel Smoothing. MixUp يمزج صورتين خطياً، CutMix يستبدل مستطيلاً من صورة أخرى؛ lambda يعكس نسبة مساهمة كل هدف في الخسارة.

              "convnext_tiny": "convnext_tiny.fb_in22k_ft_in1k",
              "efficientnetv2_s": "tf_efficientnetv2_s.in21k_ft_in1k"}
TIMM_KW = {"densenet121": {}, "convnext_tiny": {"drop_path_rate": 0.1}, "efficientnetv2_s": {"drop_path_rate": 0.1}}

class XrayNet(nn.Module):
    def __init__(self, backbone, num_classes, dropout=0.3, pretrained=True):
        super().__init__()
        self.backbone_name = backbone
        if backbone == "xrv_densenet121":
            import torchxrayvision as xrv
            base = xrv.models.DenseNet(weights="densenet121-res224-all" if pretrained else None)
            self.body, feat_dim, self.kind = base.features, 1024, "xrv"
        else:
            self.body = timm.create_model(TIMM_NAMES[backbone], pretrained=pretrained, num_classes=0, **TIMM_KW[backbone])
            feat_dim, self.kind = self.body.num_features, "timm"
            dc = timm.data.resolve_data_config({}, model=self.body)
            self.register_buffer("mean", torch.tensor(dc["mean"]).view(1, 3, 1, 1))
            self.register_buffer("std", torch.tensor(dc["std"]).view(1, 3, 1, 1))
        self.head = nn.Sequential(nn.Dropout(dropout), nn.Linear(feat_dim, num_classes))

    def forward(self, x):                      # x: (B,1,H,W) in [0,1]
        if self.kind == "xrv":
            f = F.relu(self.body(x * 2048.0 - 1024.0))
            f = F.adaptive_avg_pool2d(f, 1).flatten(1)
        else:
            f = self.body((x.expand(-1, 3, -1, -1) - self.mean) / self.std)
        return self.head(f)

    cw = compute_class_weight("balanced", classes=np.arange(NUM_CLASSES), y=y_train) ** cfg.class_weight_power
    w = torch.tensor(cw / cw.mean(), dtype=torch.float32, device=device)

def apply_mix(x, y, cfg):
    if cfg.mix_prob <= 0 or random.random() > cfg.mix_prob:
        return x, y, y, 1.0
    perm = torch.randperm(x.size(0), device=x.device)
    if random.random() < 0.5:                                   # MixUp
        lam = float(np.random.beta(cfg.mixup_alpha, cfg.mixup_alpha))
        x = lam * x + (1 - lam) * x[perm]
    else:                                                       # CutMix
        lam = float(np.random.beta(cfg.cutmix_alpha, cfg.cutmix_alpha))
        H_, W_ = x.shape[-2:]
        r = np.sqrt(1 - lam); h, w = int(H_ * r), int(W_ * r)
        cy, cx = np.random.randint(H_), np.random.randint(W_)
        y1, y2 = np.clip(cy - h // 2, 0, H_), np.clip(cy + h // 2, 0, H_)
        x1, x2 = np.clip(cx - w // 2, 0, W_), np.clip(cx + w // 2, 0, W_)
        x = x.clone(); x[:, :, y1:y2, x1:x2] = x[perm][:, :, y1:y2, x1:x2]
        lam = 1 - (y2 - y1) * (x2 - x1) / (H_ * W_)
    return x, y, y[perm], lam

def compute_metrics(y, probs):

    out = {"acc": accuracy_score(y, pred), "bal_acc": balanced_accuracy_score(y, pred),
           "f1_macro": f1_score(y, pred, average="macro")}

def tta_forward(model, x):
    zoom = TF.center_crop(F.interpolate(x, scale_factor=1.1, mode="bilinear", align_corners=False), list(x.shape[-2:]))
    views = [x, zoom, TF.rotate(x, 5), TF.rotate(x, -5)]
    return torch.stack([model(v).float() for v in views]).mean(0)

def make_param_groups(model, cfg):
    groups = []
    for part, lr in [(model.body, cfg.lr_backbone), (model.head, cfg.lr_head)]:
        dec, nodec = [], []
        for n, p in part.named_parameters():
            (nodec if p.ndim <= 1 else dec).append(p)
        groups += [{"params": dec, "lr": lr, "weight_decay": cfg.weight_decay},
                   {"params": nodec, "lr": lr, "weight_decay": 0.0}]
    return groups

def run_fold(cfg, tr_df, va_df, tag="fold", verbose=True):
    seed_everything(cfg.seed)
    tr_loader, va_loader = make_loader(tr_df, train_tfm, True), make_loader(va_df, eval_tfm, False)
    model = XrayNet(cfg.backbone, NUM_CLASSES, cfg.dropout).to(device)
    ema = AveragedModel(model, multi_avg_fn=get_ema_multi_avg_fn(cfg.ema_decay), use_buffers=True)
    crit = build_loss(cfg, tr_df.y.values)
    opt = torch.optim.AdamW(make_param_groups(model, cfg))
    total = cfg.epochs * len(tr_loader); warm = max(1, int(cfg.warmup_frac * total))
    lam_fn = lambda s: (s + 1) / warm if s < warm else 0.5 * (1 + np.cos(np.pi * (s - warm) / max(1, total - warm)))
    sched = torch.optim.lr_scheduler.LambdaLR(opt, lr_lambda=lam_fn)
    scaler = torch.amp.GradScaler("cuda", enabled=cfg.use_amp)

    best, best_state, best_logits, best_m, wait, hist = -1e9, None, None, None, 0, []
    for ep in range(1, cfg.epochs + 1):
        frozen = ep <= cfg.freeze_epochs
        set_body_trainable(model, not frozen)
        model.train()
        if frozen: model.body.eval()
        run, n, t0 = 0.0, 0, time.time()
        for x, y in tr_loader:
            x, y = x.to(device, non_blocking=True), y.to(device, non_blocking=True)
            x, ya, yb, lam = apply_mix(x, y, cfg)
            opt.zero_grad(set_to_none=True)
            with torch.autocast(device_type=device.type, enabled=cfg.use_amp):
                out = model(x)
                loss = lam * crit(out.float(), ya) + (1 - lam) * crit(out.float(), yb)
            scaler.scale(loss).backward(); scaler.unscale_(opt)
            nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            scaler.step(opt); scaler.update(); sched.step(); ema.update_parameters(model)
            run += loss.item() * len(y); n += len(y)

        lg, yv = predict_logits(ema, va_loader)
        m = compute_metrics(yv, softmax_np(lg))
        m["val_nll"] = float(F.cross_entropy(torch.tensor(lg), torch.tensor(yv)))
        hist.append({"epoch": ep, "train_loss": run / n, **m})
        score = m[cfg.monitor]
        if ep > cfg.freeze_epochs and score > best:
            best, wait, best_m, best_logits = score, 0, m, lg
            best_state = {k: v.detach().cpu().clone() for k, v in ema.module.state_dict().items()}
        elif ep > cfg.freeze_epochs:
            wait += 1
        if verbose:
            print(f"[{tag}] ep {ep:02d}{' (head only)' if frozen else ''} | loss {run/n:.4f} | val_nll {m['val_nll']:.4f} | "
                  f"acc {m['acc']:.4f} | F1 {m['f1_macro']:.4f} | AUC {m['auc']:.4f} | {time.time()-t0:.0f}s{' *' if wait == 0 and not frozen else ''}")
        if wait >= cfg.patience:
            if verbose: print(f"[{tag}] early stop @ {ep}")
            break
    return {"state": best_state, "val_logits": best_logits, "best": best, "best_metrics": best_m, "hist": pd.DataFrame(hist)}

Cross-validation وحفظ النماذج

OOF هي تنبؤات لعينة Dev من نموذج لم يتدرب عليها: كل fold يملأ مواقع validation الخاصة به. بعد التدريب يحفظ checkpoint ثم يعاد تحميله ويعاد قياس validation؛ اختلاف الدقة يكشف أخطاء حفظ/تحميل أو preprocessing. oof_tta يحتفظ بالتنبؤات مع TTA. cv_table يلخص الأداء بين الطيات؛ المتوسط والانحراف يوضحان الاستقرار لا مجرد أفضل fold.

    va_loader = make_loader(dev_df.iloc[va_i], eval_tfm, False, bs=64)

OOF والمعايرة وتحسين الانحياز

يُقارن التقييم العادي مع TTA. TTA يمرر الصورة الأصلية، zoom، ودوران ±5 درجات ثم متوسط logits؛ هذا قد يزيد الثبات لكنه يضاعف inference تقريباً أربع مرات. اختيار TTA على OOF فقط. Temperature scaling يقسم logits على T لتعديل ثقة الاحتمالات دون تغيير ترتيب الفئات عندما T موجب. ECE يقيس فجوة الثقة والدقة ضمن bins. Logit bias يضيف انحيازاً لكل فئة لتحسين Macro-F1؛ البحث الشبكي هنا مكلف جداً (21^(عدد الفئات-1)) لكنه مع 3 فئات محتمل. يجب أن تكون هذه المعايرة من OOF لا Test لتجنب leakage.

def fit_temperature(logits, y):
    ts = np.linspace(0.3, 5.0, 236)
    nll = [F.cross_entropy(torch.tensor(logits / t), torch.tensor(y)).item() for t in ts]
    return float(ts[int(np.argmin(nll))])

def ece_score(probs, y, bins=15):
    conf, ok = probs.max(1), probs.argmax(1) == y
    edges, e = np.linspace(0, 1, bins + 1), 0.0
    for lo, hi in zip(edges[:-1], edges[1:]):
        mk = (conf > lo) & (conf <= hi)
        if mk.any(): e += mk.mean() * abs(ok[mk].mean() - conf[mk].mean())
    return e

def fit_logit_bias(logits, y, grid=np.linspace(-1.0, 1.0, 21), min_gain=0.003):
    base = f1_score(y, logits.argmax(1), average="macro")
    best_f1, best_b = base, np.zeros(NUM_CLASSES)
    for combo in itertools.product(grid, repeat=NUM_CLASSES - 1):
        b = np.array([0.0, *combo])
        f = f1_score(y, (logits + b).argmax(1), average="macro")
        if f > best_f1 + 1e-9 or (abs(f - best_f1) < 1e-9 and np.abs(b).sum() < np.abs(best_b).sum()):
            best_f1, best_b = f, b
    return (best_b, best_f1) if best_f1 - base >= min_gain else (np.zeros(NUM_CLASSES), base)

    rng, vals = np.random.default_rng(seed), []

Grad-CAM وتحليل الأخطاء

Grad-CAM يستخدم hooks لالتقاط خرائط الميزات والتدرجات في طبقة عميقة. متوسط gradient مكانياً يعطي وزن كل قناة، ثم مجموع weighted activations وReLU ينتج خريطة المناطق المؤثرة في score للفئة. التطبيع يجعل الخريطة بين 0 و1. overlay يساعد في فحص ما إذا كان النموذج يركز على الرئة أم النص/الحواف. لا تعتبر الخريطة تفسيراً طبياً مؤكداً ولا تثبت السببية.

الكود الأصلي

class GradCAM:
    def __init__(self, model, layer):
        self.model, self.acts, self.grads = model, None, None
        layer.register_forward_hook(self._fwd)
    def _fwd(self, m, i, o):
        self.acts = o.detach()
        if o.requires_grad: o.register_hook(lambda g: setattr(self, "grads", g.detach()))
    def __call__(self, x, cls=None):
        self.model.eval()
        with torch.enable_grad():
            lg = self.model(x)
            probs = F.softmax(lg, 1)[0].detach().cpu().numpy()
            cls = int(lg.argmax(1)) if cls is None else cls
            self.model.zero_grad(set_to_none=True); lg[0, cls].backward()
        w = self.grads.mean((2, 3), keepdim=True)
        cam = F.relu((w * self.acts).sum(1, keepdim=True))
        cam = F.interpolate(cam, size=x.shape[-2:], mode="bilinear", align_corners=False)[0, 0]
        cam = (cam - cam.min()) / (cam.max() - cam.min() + 1e-8)
        return cam.cpu().numpy(), cls, probs

prepare_image يطبق نفس preprocessing الخاص بالتقييم. predict_image يجمع logits للنماذج، مع TTA عند اختياره، ثم bias وtemperature، ويعيد اسم الفئة والثقة واحتمالات الفئات. confidence هي أعلى احتمال للنموذج وليست احتمالاً سريرياً موثوقاً أو تشخيصاً.

def prepare_image(path):
    x = torch.from_numpy(load_gray(path)).unsqueeze(0)
    return eval_tfm(x).unsqueeze(0).to(device)

@torch.no_grad()
def predict_image(path):
    x = prepare_image(path)
    with torch.autocast(device_type=device.type, enabled=cfg.use_amp):
        lg = np.mean([(tta_forward(m, x) if USE_TTA else m(x).float()).float().cpu().numpy() for m in ens_models], axis=0)
    p = softmax_np(lg + LOGIT_BIAS, T_OPT)[0]
    return {"prediction": classes[int(p.argmax())], "confidence": float(p.max()),
            "probabilities": {c: float(v) for c, v in zip(classes, p)}}

التصدير وإعدادات النشر

TorchScript trace يحفظ نسخة قابلة للتشغيل عبر PyTorch، وONNX يصدّر الرسم لتشغيله في runtimes أخرى. dummy يحدد شكل الإدخال؛ dynamic_axes يسمح بتغير batch فقط. قد يفشل التصدير بسبب توافق المكتبات أو عمليات غير مدعومة. deploy_config يسجل الفئات والمعالجة والمعايرة والقياسات وإعدادات التدريب لضمان أن التطبيق يستخدم نفس pipeline.

ملاحظات نقدية مهمة على النسخة v4

  • تحقق من labels: تقسيم Bacterial/Viral مشتق من أسماء الملفات؛ لا تفترض أن كل تسمية صحيحة سريرياً.
  • معرّف المريض: إذا لم يتعرف regex على person أو IM، يصبح اسم الصورة group. هذا لا يضمن grouping الصحيح؛ افحص أسماء الملفات ومصدر البيانات.
  • البيانات المخزنة: CACHE يحمل الصور كلها في RAM؛ راقب استهلاك الذاكرة قبل تشغيل كامل dataset.
  • تجميع dHash: الخوارزمية الحالية تقارن كل صورة بكتل من بقية الصور، وهذا قد يكون مكلفاً جداً عند N كبير (تقريباً عمليات مقارنة مربعة). راقب الزمن والذاكرة.
  • Test split: test_folds=6 ينتج split واحداً من 6؛ نسبة الفئات قد لا تكون مثالية مع عدد مجموعات محدود.
  • Model selection: Fold واحد و10 epochs فقط اختيار استطلاعي، لا دليل نهائي على تفوق backbone.
  • اختيار TTA: معيار Macro-F1 على OOF مناسب لتجنب Test، لكن التحقق من اختلاف توزيع OOF وTest يبقى ضرورياً.
  • Logit bias: البحث الشبكي يختار انحيازات لتحسين F1 على OOF؛ قد يحدث overfit للـ OOF إذا كان عدد العينات صغيراً. الأفضل nested validation أو إبقاء المعايرة بسيطة.
  • Bootstrap: يعيد أخذ الصور كعينات مستقلة، بينما بيانات المرضى مجمعة. فاصل الثقة الأدق قد يحتاج bootstrap على مستوى patient/group لا الصورة.
  • Grad-CAM: يفسر score النموذج محلياً ولا يثبت أن المنطقة سبب التشخيص أو أن النموذج صالح سريرياً.
  • التصدير: كود deploy_config يصف preprocessing، لكن يجب مطابقة pipeline بدقة في التطبيق النهائي وإضافة اختبار parity بين PyTorch وONNX/TorchScript.
قاعدة علمية: لا تستخدم Test لاختيار architecture أو augmentation أو calibration أو threshold. اجعل Test آخر خطوة، وأبلغ عن النتائج كما هي حتى إن كانت أقل من المتوقع.
